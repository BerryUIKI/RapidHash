# Support

RapidHash is a volunteer-maintained open-source project. There is no guaranteed
response time, service-level agreement, or private end-user support channel.

## Before Requesting Help

1. Check the README, project documentation, and existing issues.
2. Confirm the behavior on the newest supported release.
3. Reduce the problem to the smallest safe reproduction.
4. Remove private paths, file names, manifests, and digests from screenshots and
   logs unless they are essential and safe to disclose.

## Where to Ask

- Use a GitHub issue for reproducible defects.
- Use a feature request for a concrete product proposal.
- Use repository discussions, when enabled, for usage questions and ideas that
  are not yet actionable.
- Follow `SECURITY.md` for vulnerabilities; never report them publicly first.

## Useful Diagnostic Information

Include the RapidHash version, installation method, operating system and
architecture, file-system type when relevant, expected and actual behavior, and
minimal reproduction steps. Do not upload sensitive input files.
